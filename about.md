# How to use the Axxit Tech Radar

### What it is

The radar shows which technologies Axxit uses, and how firmly we stand behind each one. It is
our shared answer to "what should we pick for this?" on new projects.

### Rings

- **Adopt**: our default. Use it on new projects unless there is a good reason not to.
- **Trial**: used on a real project and worth pursuing. Use where you can handle the risk.
- **Assess**: worth exploring. Not for production yet.
- **Hold**: don't start anything new with it.

### Filter by purpose

Every item is tagged with what it is for: monitoring, development tooling, programming languages
and so on. Use the purpose buttons below the radar to show only the items for one purpose.

### Contributing

Open a pull request on [GitHub](https://github.com/michiel-vanherreweghe-axxit/techradar). Each
item is a Markdown file; the README explains how to add or move one.
